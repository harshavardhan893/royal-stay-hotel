# Royal Stay Hotel Website

This is a beginner-friendly frontend hotel website developed for the MANTRA 2026 Summer School assignment.

## Website Type

Hotel Website

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- Netlify

## Pages Included

- Home
- About
- Rooms
- Gallery
- Booking
- Contact

## Features

- Responsive design for desktop and mobile
- SEO-friendly HTML structure
- Image alt text on every image
- Booking form with JavaScript confirmation
- Contact form with JavaScript confirmation
- Clean and attractive user interface

## How to Run

Open `index.html` in any web browser or visit the live website on Netlify.

## Netlify Deployment Steps

1. Create a GitHub repository.
2. Upload all project files.
3. Login to Netlify.
4. Click **Add new site → Import an existing project**.
5. Connect the GitHub repository.
6. Deploy the website.
